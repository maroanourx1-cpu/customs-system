# INX – Shipping & Customs Management System

تطبيق ويب داخلي للشركة (عربي - RTL) يعمل من الكمبيوتر والموبايل والتابلت على قاعدة بيانات مركزية واحدة.

## التشغيل السريع
1. ثبّت Python 3.9+ (من python.org).
2. افتح مجلد المشروع في الطرفية ونفّذ:
   ```
   pip install -r requirements.txt
   python app.py
   ```
   (ويندوز: دوبل كليك على `run.bat`)
3. افتح المتصفح: http://localhost:5000
4. الدخول الافتراضي: **admin / Admin@123** ← غيّر كلمة المرور فورًا من الإعدادات.

لعرض بيانات تجريبية: `python app.py --demo`

## الوصول من باقي الأجهزة
شغّل البرنامج على كمبيوتر ثابت في الشركة (سيرفر)، وباقي الموظفين يفتحون
`http://<عنوان-IP-الجهاز>:5000` من نفس الشبكة. لو عايزه على الإنترنت: انشره على سيرفر/VPS
خلف HTTPS (Nginx + شهادة SSL) — لا تعرضه على الإنترنت بدون HTTPS.

## المميزات
- حساب مستقل لكل موظف + إيقاف الحسابات + صلاحيات (إضافة / تعديل / حذف / مدير).
- ملف لكل شحنة: اسم الشركة، الموقع، الرقم الضريبي، البوليصة، عدد الطرود، الوزن، قيمة الفاتورة، التعاقد، ACID، غرض الاستخدام، البند، المنشأ، الصنف، 46، المورد + شركة الشحن وتاريخ الوصول والموظف المسؤول والملاحظات.
- رفع وتحميل المستندات (فاتورة، بوليصة، شهادة منشأ، إذن تسليم، جمارك، أخرى) + كشف المستندات الناقصة.
- 9 مراحل لمتابعة الشحنة (من استلام المستندات حتى الإغلاق وتسوية الحساب)، ولكل مرحلة تاريخ والموظف المسؤول عنها (جدول «تتبع مراحل الشحنة» داخل الشحنة).
- بحث متقدم (عميل، بوليصة، رقم شحنة، شركة شحن، تاريخ، حالة).
- تقارير بالتاريخ مع رسم الحالات + تصدير CSV (يفتح في Excel) + طباعة.
- سجل كامل لكل عملية (من أضاف/عدّل/حمّل/حذف ومتى) — للمدير.
- الحذف يحتاج صلاحية، وهو حذف منطقي (البيانات تبقى في قاعدة البيانات والسجل).
- نسخ احتياطي تلقائي كل 24 ساعة + نسخ يدوي + استعادة من ملف (من الإعدادات).

## اسكان المستندات (لمدير النظام فقط)
زر **اسكان** في صفحة الشحنات: اختر صورة المستند فتتعمل شحنة جديدة بكل البيانات المقروءة منه، والصورة تُحفظ في مستنداتها.
- **Gemini (الأدق، يقرأ الخط اليد والـ PDF):** مفتاح مجاني من Google AI Studio (aistudio.google.com ← Get API key)، يُلصق من الإعدادات. يحتاج إنترنت.
- **Tesseract (بدون إنترنت):** ثبّته على جهاز السيرفر وسيُستخدم تلقائيًا لو مفيش مفتاح أو لو Gemini فشل. ويندوز: نسخة UB Mannheim واختار لغة Arabic وقت التثبيت. يقرأ الصور المطبوعة الواضحة فقط.

## جديد في INX
- **الشات الداخلي** بين كل الموظفين: رسائل وملفات، وربط أي رسالة برقم شحنة، وعلامة "قُرئت".
- **الأوامر والمهام:** أمر تكليف من موظف لموظف على شحنة محددة. يظهر للمستلم **تنبيه أحمر (مع صوت) على كل الصفحات** لحد ما يفتح الأمر. بيتسجل وقت الإرسال ووقت القراءة. الحالات: جديد ← تم الاطلاع ← جاري التنفيذ ← مكتمل.
- **الاختيارات (العروض):** زر داخل كل شحنة، أكثر من عرض (الجهة، الخدمة، السعر، العملة، التفاصيل)، جدول مقارنة (الأقل سعرًا + الفرق %)، واعتماد عرض واحد باسم من اعتمده. صلاحية الاعتماد من صفحة الموظفين ("اعتماد العروض")، والمدير يملكها دائمًا.
- **حقول جديدة للشحنة:** رقم الأوردر، الوزن القائم والصافي، عملة الفاتورة (وباقي الحقول موجودة: الطرود، المورد، ACID) مع بحث وتصفية بها.
- **سحب المستندات:** تفريغ، يورو وان، استثمار، إيصال نولون، عقد ملحق 4، موافقة السياحة (+ الأنواع القديمة). تحدد المطلوب لكل شحنة، وحالة كل مستند (مطلوب / تم السحب / لم يتم السحب) مع تاريخ السحب والموظف المسؤول ورفع نسخة إلكترونية. صفحة "سحب المستندات" تعرض الناقص على كل الشحنات.
- **السجل:** كل إضافة/تعديل/أمر/عرض/سحب مستند بيتسجل باسم الموظف ووقته، ومتاح فلترته من "سجل التعديلات".
- **الترقية من النسخة القديمة:** انسخ مجلد `data/` القديم جنب الكود الجديد وشغّل. الجداول والأعمدة الجديدة بتتضاف تلقائيًا بدون حذف أي بيانات أو مستندات. (حقل "الوزن" القديم صار "الوزن القائم").
- **الشعار:** الملف `static/logo.svg` — استبدله بشعار INX الرسمي لو عندك (بنفس الاسم).

- **العروض الرقابية:** قسم داخل كل شحنة (زراعة، مصنفات، كيمياء، إشعاع، صيدلة، أمن عام، مخدرات، واردات صناعية، مفرقعات) — اختيار أكثر من عرض، الجهة المختصة، رقم الطلب، تاريخ التقديم، المسؤول عن المتابعة، الحالة (مطلوب / تم التقديم / تحت الفحص / تمت الموافقة / مرفوض)، رفع الموافقات وتاريخ صدورها. تغيير الحالة يرسل تنبيهًا (رسالة شات مربوطة بالشحنة) للمسؤول عن المتابعة ولمسؤول الشحنة. صفحة «العروض الرقابية» تعرض الناقص/المعلق مع تصدير CSV. المدير يضيف أنواعًا جديدة من الإعدادات ← إدارة أنواع العروض الرقابية. المرحلة 4 تنتقل تلقائيًا عندما تحصل كل العروض المسجلة على موافقة.
- **ترحيل المراحل:** أول تشغيل للنسخة الجديدة يحوّل الشحنات القديمة تلقائيًا (مرة واحدة فقط، مسجلة في جدول `meta`) فتبقى كل شحنة على نفس مرحلتها الفعلية بعد إضافة المرحلة 4.
- **جدول الشحنات:** يعرض مباشرة العميل والمورد وACID وVAT والطرود والوزن (قائم/صافي) والعملة وشركة الشحن والموظف والحالة، مع بحث وتصفية وترتيب بالتاريخ أو الحالة أو الموظف.
- **إشعارات العروض:** إضافة عرض أو اعتماده يرسل إشعارًا لمسؤول الشحنة.

## الأمان
كلمات المرور مشفّرة (hash)، حماية CSRF، حد لمحاولات الدخول الفاشلة، رفع الملفات بأنواع مسموحة فقط،
والملفات تُخزَّن بأسماء عشوائية. كل البيانات في مجلد `data/` (قاعدة البيانات + المستندات + النسخ الاحتياطية)
— انسخه دوريًا خارج الجهاز أيضًا.

## التطوير مستقبلاً
الكود منظم (`app.py` + `templates/`) ويمكن إضافة الحسابات المالية ومستحقات العملاء كجداول وصفحات جديدة.

## تحديث الواجهة (UI/UX) + جداول Excel
**بنية الملفات الجديدة**
```
app.py            النظام الأساسي (المسارات + قاعدة البيانات)
ui.py             مصدر واحد للتنقل: القائمة الجانبية + الشريط السفلي للموبايل + لوحة البحث السريع
sheets.py         وحدة جداول Excel (حفظ/استيراد/تصدير/إنشاء من الشحنات)
static/css/core.css    الألوان والتخطيط والمكوّنات والحركة     (تعديل الشكل العام من هنا)
static/css/pages.css   صفحات بعينها: الدخول، الشات، السحب، العروض، قائمة الجداول
static/css/sheets.css  محرر الجداول
static/js/core.js      سلوك الواجهة: القائمة، Ctrl+K، نافذة التأكيد، الإشعارات
static/js/xl-formula.js محرك المعادلات (بدون مكتبات خارجية)
static/js/sheets.js     واجهة الجدول
```
**أهم التحسينات:** قائمة جانبية مجمّعة تتحول لشريط أيقونات (وتُحفظ)، شريط سفلي للموبايل، بحث سريع `Ctrl+K` (صفحات + شحنات + إجراءات)،
صفحة رئيسية تعرض «ما يحتاج انتباهك» أولًا، فلاتر الشحنات قابلة للطي مع تبويبات حالة سريعة، الجدول يتحول لبطاقات على الموبايل،
شريط تنقل داخلي في صفحة الشحنة، الإعدادات في تبويبات، نافذة تأكيد بدل `confirm()`، وانتقالات سريعة (View Transitions) تحترم «تقليل الحركة».

**جداول Excel (قسم «جداول Excel» في القائمة):** شبكة كاملة بمعادلات (SUM, AVERAGE, IF, IFERROR, VLOOKUP, SUMIF, COUNTIF, ROUND, TEXT… وأكثر من 45 دالة)،
مراجع بين الأوراق `Sheet2!A1`، نسخ/لصق من وإلى Excel، تعبئة بالسحب وCtrl+D/R، ترتيب، تثبيت الصف الأول، تنسيق (عريض/ألوان/محاذاة/حدود/أرقام/نسبة)،
إدراج/حذف صفوف وأعمدة مع تعديل المعادلات، تراجع/إعادة، بحث Ctrl+F، حفظ تلقائي مع كشف تعارض بين مستخدمين،
واستيراد `.xlsx/.csv` وتصدير `.xlsx/.csv`. زر **«فتح في Excel»** في صفحة الشحنات يحوّل نتائج البحث الحالية لجدول جاهز بإجماليات.
الصلاحيات: العرض للجميع، التعديل لمن عنده صلاحية «تعديل»، الإنشاء لمن عنده «إضافة»، والحذف لصاحب الجدول أو «حذف»/المدير.
> يحتاج مكتبة `openpyxl` (موجودة في requirements.txt): `pip install -r requirements.txt`
